#  Détection de Mutations Virales par Deep Learning

##  Description
Ce projet utilise le Deep Learning pour détecter si une séquence génomique virale
contient une mutation (variant) ou non (séquence de référence).

##  Problème
- **Entrée** : Séquence ADN/ARN d'un virus (format texte)
- **Sortie** : 0 = Non muté (référence) | 1 = Muté (variant)
